## From problem to working prototype

**Understand → Design → Build → Validate → Improve**

<details>
<summary><strong>See how I approach an automation project</strong></summary>

1. **Understand the process.** Identify the users, inputs, repetitive steps, and expected output.
2. **Choose the right approach.** Use AI for language tasks and code for calculations and business rules.
3. **Build a focused workflow.** Separate ingestion, retrieval, analysis, validation, and reporting.
4. **Keep people in control.** Include human review for consequential decisions.
5. **Test and improve.** Check individual modules, handle missing information, and document limitations.

</details>

<details>
<summary><strong>Explore collaboration areas</strong></summary>

- **Document workflows:** extract, organize, and retrieve information from business documents.
- **Knowledge assistants:** make a defined document collection searchable through natural language.
- **Support prototypes:** classify customer questions and retrieve answers from business records.
- **Business reporting:** calculate metrics and generate readable summaries.
- **AI application MVPs:** turn a focused use case into a demonstrable Python application.

</details>
